# Context Engineering 方法论详解

本质一句话：**把模型每轮看到的所有 token 当一等公民来设计，而不是让 SDK 默认值替你决定。**

CE 不替代 Prompt 工程，是叠在它上面的一层——PE 管「那段文字写得好不好」，CE 管「这一整轮的输入是怎么装配出来的、有没有你没意识到塞进去的东西」。

---

## 七层次：模型每轮看到什么

任何 LLM 应用，单轮输入都能拆成 7 层。逐层问四问：**内容是什么 / 谁来填 / 多少 token / 怎么 cache + 压缩**。

- **Layer 1 系统提示**——角色、行为准则、边界。相对稳定，最该进 cache。常被 SDK preset / `setting_sources` 偷塞。
- **Layer 2 指令**——任务特定、优先级、运行时动态追加的规则。注意「代码拼装时丢规则」（写了≠每轮真带）。
- **Layer 3 用户输入**——当前 turn。语音场景是 ASR 文本，可能带错字，靠 prompt 层兜底。
- **Layer 4 结构化 IO**——JSON schema、模板、response_format。
- **Layer 5 工具集成**——MCP / function calling 的 schema。eager（写进 system）vs deferred（按需拉，首用有 round-trip 成本）。
- **Layer 6 RAG 与记忆**——向量库、CLAUDE.md、call_summary。跨 session 记忆在这层注入。
- **Layer 7 状态与历史**——对话历史、用户画像、stage tracker。**最易暗物质 + 最易爆量**：框架托管的 history 随轮数线性膨胀，代码里看不到。

> ⚠️ 第 1、6、7 层最容易被框架默默塞。**第一步不是优化，是让 7 层 100% 可见。**

---

## 暗物质：CE 最核心的概念

**暗物质 = 你以为没塞、实际被默默塞进每一轮的 token。** 两个来源：① SDK 默认值（如 `setting_sources` 偷加载 CLAUDE.md）② 框架托管的状态（如对话历史越拼越长）。

**问题**：不照出来，你优化 prompt 文字救不了它——慢/贵的根源不在你打磨的那段文字里。

**做法**：
- 逐层填 CONTEXT.md，每一格空着都是一个不能跳过的问题，逼你去查代码。
- 打 `input_tokens` / `cache_read` 日志，让每轮真实用量可见。
- **按实跑通路判定**：你不走某 SDK，它的坑就不存在——别照搬别项目的坑库。

> 反例：把别项目的「`setting_sources` 17k」抄进来当头号暗物质，但你的生产用 OpenAI 兼容端点直连、根本不走那个 SDK——那 17k 不存在。照搬坑库 = 假审计。

## 五原则

- **整体设计**——7 层互联，改 system 影响 tool 选用，加 RAG 让 system 指令失效，不能孤立优化。
- **迭代优化**——每改一次跑 baseline 看 token/耗时/cache 命中/完成率，不凭感觉。
- **用户中心**——别为压 token 把 system 削到模型乱答。指标服务体验。
- **可扩展性**——扛得住 10× 复杂度（10× tool / 10× 历史），一开始就分层 cache。
- **可维护性**——CONTEXT.md 是活文档，跟业务演进，不是一次性产物。

## 上下文生命周期：何时建 / 读 / 优化

CONTEXT.md 是给人和 agent 读的文档，**运行时模型从不碰它**。它的生命周期：

```
创建 CREATE   触发 = 写第一行 LLM 调用代码【之前】/ 接手没有 CONTEXT.md 的旧项目
              动作 = 逐层填 7 层表，把隐性上下文显性化
   │
读 READ       触发 = 改任何 prompt/拼装代码【之前】/ 要优化时 / review 改了上下文的 PR
              动作 = 先看全貌再动手，当作战地图
   │
优化 OPTIMIZE 触发 = ① 填表时撞见暗物质/bug（被动）② 信号：慢/贵/爆/怪故障 ③ 里程碑定期核对
              动作 = 照暗物质清单 + 静态动态表治装配 → 跑 baseline 对照
   │
回填          改完 prompt/拼装后更新 CONTEXT.md（防腐）→ 回到 READ
```

三句话：**建在写码前，读在改动前，优化在信号触发或填表撞见时。**

## 一句话收口

> prompt 文件让模型**能跑**，CONTEXT.md 让人**看得清模型在跑什么**。
> 镜子不参与做菜，但没镜子你不知道自己脸上有没有黑。
